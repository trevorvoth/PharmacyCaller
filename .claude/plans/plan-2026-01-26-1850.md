# Plan: Include All Nearby Pharmacies in Search Results

**Session ID:** plan-2026-01-26-1850
**Created:** 2026-01-26

## Problem Statement

Pharmacies closer to the user's location are not appearing in search results. Investigation reveals that pharmacies without phone numbers from Google Places are excluded from results. NPPES enrichment should provide phone numbers for these pharmacies but may be failing due to name matching or address parsing issues. Users are missing nearby pharmacy options that could have medication availability.

## Scope & Boundaries

**In Scope:**
- Include pharmacies without Google phone numbers in search results
- Add logging to track why NPPES enrichment fails (name matching, address parsing)
- Update frontend to display pharmacies without phone numbers appropriately
- Improve NPPES name matching or address parsing if specific issues found
- Adjust Google Places API parameters if beneficial for getting better results

**Out of Scope:**
- Performance optimizations
- Adding new phone data sources beyond NPPES
- Call functionality for phoneless pharmacies (they'll be display-only)

## Success Criteria

- [ ] Search results include ALL pharmacies within radius, regardless of phone availability
- [ ] Pharmacies are sorted by distance (closest first)
- [ ] Pharmacies without phone numbers display with "Phone N/A" in UI
- [ ] NPPES lookup attempts are logged for debugging (success, failure, reason)
- [ ] NPPES enrichment runs for pharmacies without Google phone numbers
- [ ] Server starts without errors
- [ ] Lint passes
