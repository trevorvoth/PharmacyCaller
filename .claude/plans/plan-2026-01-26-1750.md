# Plan: Fix NPPES Phone Enrichment

**Session ID:** plan-2026-01-26-1750
**Created:** 2026-01-26

## Problem Statement

The NPPES (National Provider Identifier Registry) phone enrichment feature is not working. All pharmacy phone numbers are coming from Google Places API only. Pharmacies without Google phone numbers are either missing from results or shown without phone numbers.

**Root Cause:** The `_transformPlacesForEnrichment()` function adds ALL pharmacies (including those without phones) to the `withPhone` array, which populates `allResults`. The NPPES enrichment condition `allResults.length < targetPharmacyCount` evaluates to false before enrichment can run because the count already includes pharmacies without phones.

**Secondary Issue:** When enrichment does run, pharmacies are added without deduplication, creating duplicate entries.

## Scope & Boundaries

**In Scope:**
- Fix `_transformPlacesForEnrichment()` to properly separate pharmacies with/without phones
- Fix deduplication when merging enriched pharmacies
- Add info-level logging for NPPES enrichment operations
- Create log file output for NPPES data review

**Out of Scope:**
- UI changes (phone source already displays in frontend)
- Changes to Google Places API integration
- Changes to NPPES API service itself (only how it's called)
- Performance optimizations
