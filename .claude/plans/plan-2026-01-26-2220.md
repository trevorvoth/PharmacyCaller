# Plan: Fix Chain Filter Returning Limited Results

**Session ID:** plan-2026-01-26-2220
**Created:** 2026-01-26

## Problem Statement

When users filter pharmacy search results by chain (e.g., CVS, Walgreens), fewer pharmacies appear than expected. This is because:
1. Chain filtering happens post-fetch (after Google returns results)
2. A page of 20 results might only contain 2-3 matching pharmacies
3. The current `maxPages=10` limit may not fetch enough pages to collect sufficient filtered results
4. With `rankPreference: 'DISTANCE'`, Google returns fewer total results

Users filtering for specific chains in areas with sparse chain presence see very few results.

## Scope & Boundaries

**In Scope:**
- Increase `maxPages` when chain filter is active (10 → 30)
- Increase radius when filtering to cast wider net (5mi → 15mi)
- Add logging to track filter effectiveness
- Ensure pagination continues appropriately with filters

**Out of Scope:**
- Changing to a different Google API (Text Search)
- Moving filtering to client-side
- Adding new chain types
- Changing the chain detection logic

## Success Criteria

- [ ] Chain-filtered searches return more results than before
- [ ] Filter for a single chain (e.g., CVS) returns all nearby CVS locations within expanded radius
- [ ] Pagination correctly continues when filters reduce per-page results
- [ ] Search completes in reasonable time (< 10 seconds with filters)
- [ ] Server starts without errors
- [ ] TypeScript build passes
