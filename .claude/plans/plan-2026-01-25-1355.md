# Plan: Fix Missing Nearby Pharmacies in Search Results

**Session ID:** plan-2026-01-25-1355
**Created:** 2026-01-25

## Problem Statement

The pharmacy search is not returning the closest pharmacies to the user's location. Google Places API returns results by "prominence" (ratings, popularity) rather than by distance, causing nearby pharmacies to be missed while more distant but popular pharmacies are shown.

**Root Cause:** The code explicitly avoids using `rankPreference: 'DISTANCE'` in the Google Places API request (see comment on line 82-83 of `googlePlaces.ts`).

## Scope & Boundaries

**In Scope:**
- Modify Google Places API request to use distance-based ranking
- Update/remove the outdated code comment explaining the current behavior

**Out of Scope:**
- UI changes
- Changing the number of pharmacies returned
- Modifying NPPES enrichment logic

## Success Criteria

- Search results are ordered by distance from user's location
- Closest pharmacies appear first in results
- No significant increase in API costs

## Technical Details

**File to modify:** `src/services/googlePlaces.ts`

**Change location:** Lines 82-88 in the `searchPharmaciesNearby` function

**Current code:**
```typescript
// Note: We don't use rankPreference: 'DISTANCE' as it limits results
// Instead, we sort by distance ourselves in pharmacySearch.ts after fetching
const requestBody: Record<string, any> = {
  includedTypes: ['pharmacy'],
  maxResultCount: maxResults,
};
```

**New code:**
```typescript
// Use DISTANCE ranking to ensure closest pharmacies are returned first
// Pagination handles cases where results per page are limited
const requestBody: Record<string, any> = {
  includedTypes: ['pharmacy'],
  maxResultCount: maxResults,
  rankPreference: 'DISTANCE',
};
```
