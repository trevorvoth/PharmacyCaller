# Plan: Improve Pharmacy Phone Number Coverage with NPPES API

**Session:** `plan-2026-01-24-1235`
**Created:** 2026-01-24
**Status:** Ready for execution

---

## 1. Problem Statement

The pharmacy search feature currently relies solely on Google Places API for pharmacy data. However, Google Places only has phone numbers for approximately 20% of pharmacy listings. Since phone numbers are required to initiate calls, this severely limits the pool of pharmacies we can contact.

**Solution:** Integrate the free CMS NPPES (National Plan and Provider Enumeration System) API to enrich pharmacy records with phone numbers. The NPPES database contains all licensed healthcare providers in the US, including ~80,000 pharmacies with phone numbers.

---

**OUT OF SCOPE:**
- UI changes (no frontend modifications)
- Chain-specific APIs (Walgreens, CVS) - can be added later

**Implementation Details:**

### Task 1: NPPES API Service
- Endpoint: `https://npiregistry.cms.hhs.gov/api/?version=2.1`
- No API key required (free public API)
- Search by: `taxonomy_description=Pharmacy`, `state`, `city`, `organization_name`
- Returns: `telephone_number`, `fax_number` in addresses array

### Task 2-3: Enrichment Logic
1. Get pharmacies from Google Places (existing flow)
2. Filter pharmacies without phone numbers
3. For each, query NPPES by organization name + city + state
4. Match results and extract phone number
5. Return enriched pharmacy list

## Research Summary

**NPPES API Details:**
- **Endpoint:** `https://npiregistry.cms.hhs.gov/api/?version=2.1`
- **Authentication:** None required (free public API)
- **Coverage:** ~80,000+ US pharmacies
- **Taxonomy code:** `333600000X` (Pharmacy)
- **Returns:** Name, address, telephone_number, fax_number

**Example Response:**
```json
{
  "addresses": [{
    "telephone_number": "323-298-7693",
    "fax_number": "323-298-0443",
    "city": "LOS ANGELES",
    "state": "CA"
  }],
  "basic": {
    "organization_name": "10TH AVENUE PHARMACY"
  }
}
```

**Sources:**
- [NPPES NPI Registry](https://npiregistry.cms.hhs.gov/)
- [NPPES API Documentation](https://npiregistry.cms.hhs.gov/api-page)
- [NPI Files Download](https://download.cms.gov/nppes/NPI_Files.html)

## Approach Selected

**NPPES API Enrichment**

Use the free CMS NPPES API to enrich pharmacy records that are missing phone numbers from Google Places. This provides:
- Near-complete coverage (~80,000 pharmacies)
- Zero cost (no API fees)
- No registration required
- Official government data source
